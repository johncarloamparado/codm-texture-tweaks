What does this do?

This sets Pixel Blocks (Chunky, 8), no start delay, render scale off, early hook (hook delay 0) and a minimum texture size of 64. It overwrites: Look (all modes), Start delay, Min size, Render scale, Hook delay and Module mode. It does not touch: FPS cap, the Freeze/Thread/Core logs or the skip lists.

Compatibility

Use this if CODM crashes or goes back to the lobby when another loader or mod runs together with this module.

Hook timingEarly

A later timing can miss the first textures and the startup render scale. Keep it on Early unless you have a crash.

Texture groups

Turn a group off to leave those textures original. Play one match first so the list can fill in.

A group is one format and size. Walls and floors can share a group, so switching it off affects both.

Skip Manager

Manage custom skip rules. Textures matching these rules stay original. Use format size or format width height.

Built-in rules are controlled by the Quick fixes on Home. Switch one off or delete it to let that texture be changed. Reset defaults restores them. Drag a rule by its handle to move it, or drop it on another rule to group them. A new or changed rule is read only when CODM starts: tap Save.

This is not a save button. It only sends information to the developer when you report a bug. Save applies your settings.

Export report makes one file in CODM Log in internal storage, named CODM_report_name (a new export replaces the old one; the date, brand and model are inside the file). Inside are the log, device info, settings, settings folder, other modules and crash info. It is a .zip when the phone can make one, otherwise .tar.gz or .txt. Send that single file to the developer.
