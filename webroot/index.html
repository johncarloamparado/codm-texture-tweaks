Quick fixes
Scope textureCustom

While on, a very small number of textures stay original.

Why only one? The reticle and the grass use the same texture. Keeping it original keeps the reticle clear, but grass stays smooth. Changing it makes grass blocky, but the reticle turns blocky too. There is no setting where both look good at the same time.

  • FPS — frames drawn per second over the whole session. Higher is smoother.
  • Avg ms — average time per frame. 16.7 ms is 60 FPS and 33 ms is 30 FPS. Lower is better.
  • 99th ms — 99 out of 100 frames were faster than this (typical over the session). If it is far above Avg, the game stutters.
  • Freezes — frames that took longer than 100 ms. Ideally 0.

Advice

History

Your last sessions (about a minute or longer) with the settings they ran on, so you can see what a change did. Kept in this app only.

Startup

Gives the game time to finish loading menus and UI before textures are changed.

Off

Textures created in the first seconds are held back and changed once the delay is over (v0.38). Until then the game looks original, so keep it Off unless you need it.

Fine tuning

Leave very small textures alone so icons, scopes and UI stay clear.

Smallest texture to change64 px

Anything smaller than this stays original.

Compatibility

Use this if CODM crashes or goes back to the lobby when another loader or mod runs together with this module.

Hook timingEarly

A later timing can miss the first textures and the startup render scale. Keep it on Early unless you have a crash.

Texture hider

Keep smoke soft leaves transparent textures smooth. The texture finder finds one single texture on this phone by switching off half of the list at a time, and keeps what it finds in the My textures card below.

Texture finderOff

Needs the v0.53 module and a list: play one match with logs on, stay in it until the thing you are looking for is on screen, then tap Refresh list. Use a mode without rank points.

Texture browser

Every texture the module has seen on this phone. Search or filter the list, tick the textures you want, then test, hide, show or save exactly those. The small switch hides just one texture. Tap Save at the bottom to try it in the game. If it worked, save it with a name.

My textures

Everything the Texture finder found. Each one (or each set of textures that work together) has its own on / off switch. Tap Save at the bottom after you change one.

Texture groups

Turn a group off to leave those textures original. Play one match first so the list can fill in.

A group is one format and size. Walls and floors can share a group, so switching it off affects both.

Skip Manager

Manage custom skip rules. Textures matching these rules stay original. Use format size or format width height.

Built-in rules are controlled by the Quick fixes on Home. Switch one off or delete it to let that texture be changed. Reset defaults restores them. Drag a rule by its handle to move it, or drop it on another rule to group them. A new or changed rule is read only when CODM starts: tap Save.

Renderer

Every effect here only works on OpenGL ES. With this on, CODM cannot use Vulkan and starts on OpenGL ES instead. Takes effect the next time CODM starts. This does not add Vulkan support.

What does this do?

This sets Pixel Blocks (Chunky, 8), no start delay, render scale off, early hook (hook delay 0) and a minimum texture size of 64. It overwrites: Look (all modes), Start delay, Min size, Render scale, Hook delay and Module mode. It does not touch: FPS cap, the Freeze/Thread/Core logs or the skip lists.

Game copy

Checking log…

Added to the file name so the developer knows whose report it is. Letters, numbers, - and _ only.

This is not a save button. It only sends information to the developer when you report a bug. Save applies your settings.

Export report makes one file in CODM Log in internal storage, named CODM_report_name (a new export replaces the old one; the date, brand and model are inside the file). Inside are the log, device info, settings, settings folder, other modules and crash info. It is a .zip when the phone can make one, otherwise .tar.gz or .txt. Send that single file to the developer.
